# READLINE Website

A responsive website for a mechanic shop where customers can view available services and submit appointment or repair requests. Submitted information will be securely sent to the shop owner by email.

## Project Status

Currently under development.

## Planned Features

* Responsive homepage
* Automotive services section
* Appointment request form
* Customer contact form
* Email notifications for new requests
* Form validation
* Mobile-friendly design
* Security protections against spam and malicious submissions

## Technologies

* HTML
* CSS
* JavaScript
* Git and GitHub

Additional backend technologies will be added when the email system is implemented.

## Project Structure

```text
mechanic-shop-website/
├── index.html

├── README.md
└── .gitignore
```

## Running the Website

Clone the private repository:

```bash
git clone git@github.com:C3mil9/mechanic-shop-website.git
```

Enter the project folder:

```bash
cd mechanic-shop-website
```

Open `index.html` in a web browser or use the Live Server extension in Visual Studio Code.

## Security

This repository should never contain:

* Passwords
* Email credentials
* API keys
* Customer information
* `.env` files

Sensitive information will be stored using environment variables or the hosting provider’s protected secrets.
